# 欢迎使用 TigerMark

跨平台桌面 **Markdown** 编辑器：本地优先，打开文件夹即可开始写作。

## 功能概览

- 左侧目录管理（新建 / 重命名 / 删除）
- 编辑、分屏、预览三种视图
- 剪贴板图片粘贴（保存到 `assets/`）
- 工具栏：标题、表格、JSON 格式化
- 支持 Windows、macOS、Linux

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl/⌘ + O` | 打开文件夹 |
| `Ctrl/⌘ + S` | 保存 |
| `Ctrl/⌘ + 1` | 仅编辑 |
| `Ctrl/⌘ + 2` | 分屏 |
| `Ctrl/⌘ + 3` | 仅预览 |
