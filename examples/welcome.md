# 欢迎使用 TigerMark

这是一个跨平台桌面 **Markdown** 编辑器。

## 功能概览

- 左侧目录管理
- 右侧编辑 / 预览分屏
- 支持 Windows、macOS、Linux

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl/⌘ + O` | 打开文件夹 |
| `Ctrl/⌘ + S` | 保存 |
| `Ctrl/⌘ + 1` | 仅编辑 |
| `Ctrl/⌘ + 2` | 分屏 |
| `Ctrl/⌘ + 3` | 仅预览 |
